## 🧩 About

Nimbus Weather is a mobile application built using React Native and Expo that provides real-time weather updates.
Users can check weather based on their current location or search for any city.
The app focuses on simplicity, performance, and a clean user interface.

---

## ✨ Features

* 📍 Automatic location detection
* 🔍 Search weather by city
* 🌡️ Temperature, humidity, and wind details
* ⭐ Save favorite locations
* ⚠️ Weather alerts
* 🗺️ Radar map support

---

## ⚙️ Tech Stack

* React Native (Expo)
* TypeScript
* AsyncStorage
* Expo Location
* React Native Maps

```

     → Process Response
```
